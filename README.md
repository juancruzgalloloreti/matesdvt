# Lista de precios

Página estática: no necesita servidor ni instalar nada. Abrí `index.html` para verla.

## Cambiar precios o productos
Editá `js/products.js` (cada producto es una línea). Para una foto nueva, ponela en `img/productos/` (mejor en WebP o JPG, de unos 800 px de lado) y escribí su ruta en `img`.
También ahí podés cambiar el WhatsApp, el Instagram y la fecha de actualización.

## Subirla a internet (gratis)
- **Netlify Drop**: entrá a app.netlify.com/drop y arrastrá la carpeta completa.
- **Cloudflare Pages** o **GitHub Pages**: subí la carpeta tal cual; `index.html` tiene que quedar en la raíz.

## Estructura
- `index.html` estructura · `css/styles.css` diseño · `js/app.js` funcionamiento · `js/products.js` datos
- `fonts/` tipografías incluidas · `img/productos/` fotos · `img/logo.webp` logo · `favicon.png` ícono de la pestaña
